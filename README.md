# Task Management System 🚀

## 📌 Overview

The **Task Management System** is a full-stack Java application that helps users manage daily tasks efficiently. It allows users to create, update, delete, and track tasks in an organized way.

---

## ✨ Features

* ➕ Add new tasks
* 📝 Update existing tasks
* ❌ Delete tasks
* 📋 View all tasks
* 📊 Organized task tracking

---

## 🛠️ Tech Stack

* **Backend:** Java, Spring Boot
* **Frontend:** HTML, CSS, JavaScript
* **Database:** MySQL
* **Tools:** Git, GitHub

---

## 📂 Project Structure

* `WebApp/` → Frontend files
* `src/` → Backend (Spring Boot)
* `resources/` → Configuration files

---

## 🚀 How to Run

1. Clone the repository
2. Open in IDE (IntelliJ / Eclipse)
3. Configure MySQL database
4. Run the Spring Boot application
5. Open browser and access the app
